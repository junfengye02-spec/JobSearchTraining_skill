# Adaptive Interview Coach

一个面向 Codex 的求职与面试训练 Skill：自动发现匹配岗位，维护岗位 Excel，根据最新简历和岗位职责出题，讲解薄弱点，并把复习过程记录下来。

## 能做什么

### 1. 自动找岗位

- 根据目标届别、岗位方向、城市、企业类型和是否包含实习进行搜索。
- 固定覆盖牛客、企业招聘公众号与官网、51job/智联/猎聘校园、校招名单与实习僧四路来源。
- 多个岗位方向会分别生成搜索词，并优先使用牛客等平台的公开站内搜索入口，不会把所有方向拼成一个难以命中的精确短语。
- 优先使用企业官方招聘页，聚合平台作为补充来源，并核实新出现的企业。
- 记录每路实际查询、访问页面和成功/为空/受阻/报错状态。
- 至少三路真实完成搜索且留下查询和访问页面证据后，才允许报告“本轮没有岗位”；缺少联网工具时会明确报阻塞。
- 记录岗位名称、完整岗位职责、公司、城市、岗位性质、来源链接和核实状态。
- 对岗位进行去重、匹配度评估和能力缺口分析。
- 只有有明确证据时才标记岗位失效。

### 2. 维护岗位 Excel

Skill 会持续维护一份岗位总表，而不是每天创建副本：

- `岗位总表.xlsx`
- `岗位名称`和`岗位职责`固定为前两列。
- `职责画像`工作表每天根据全部有效岗位和当日新增岗位重新生成。
- 来源链接可点击。
- 有效岗位和已失效岗位分开保存。
- 匹配依据和简历能力缺口随岗位更新。

### 3. 基于简历和岗位职责面试

每日读取最新简历和岗位表，优先从高匹配岗位的真实职责出题，覆盖：

- 简历项目深挖和个人贡献核验。
- Java、JVM、并发、Spring、MySQL、Redis、消息队列和微服务。
- AI Agent、RAG、Function Calling、工具调用、评测和安全。
- 算法题、系统设计和近期公开面经中的问题。

每天搜岗结束后，Skill 会把全部有效岗位职责重新聚类，生成动态的`职责画像`。当天新增岗位会改变各职责类别的覆盖率、优先级和`新增/上升/稳定/下降`趋势。

每道新主问题都必须建立以下对应关系：

```text
每日更新的岗位职责画像 → 最新简历中的项目/技能/数据或能力缺口 → 面试问题
```

问题前会显示简短的`职责画像依据`，包含归纳职责、覆盖率或优先级及代表岗位。Java 八股、AI、算法和系统设计也必须服务于这条职责画像与简历的对应关系，不能脱离目标岗位随意出通用题。

一次只问一道主问题，根据回答继续追问，不提前展示答案。后续薄弱点记录会保留职责画像版本、归纳职责、代表岗位以及对应的简历证据或缺口。

### 4. 发现薄弱点后先讲清楚

发现薄弱点时会暂停下一道题，依次完成：

1. 指出原回答具体哪里有问题。
2. 解释正确结论、直观理解和底层原理。
3. 结合简历项目、代码或系统设计举例。
4. 给出大厂回答框架、关键词和常见追问陷阱。
5. 用确认题或复述检查是否真正掌握。

没有确认掌握前不会进入下一个主问题。

### 5. 维护薄弱点复习 Excel

自动维护一份复习表：

- `面试薄弱点复习表.xlsx`
- 薄弱点明细和知识点去重。
- 正确结论、原理讲解、项目示例和回答框架。
- 掌握状态、掌握度、复习次数和下次复习日期。
- 每次确认题和复习都追加历史记录。

默认复习间隔为：0-2 分次日，3-4 分三天后，5 分七天后。

### 6. 自动化和七天轮换

支持：

- 每日岗位刷新。
- 每日固定时间面试。
- 一个面试任务使用指定天数后自动创建新任务。
- 继承已问主题、薄弱点和未掌握内容。
- 归档旧任务，避免每天创建新任务。

## 如何使用

### 一句话启动全部流程

安装完成后，在包含简历的 Codex 项目中直接发送：

```text
开始skill
```

Skill 会在同一次启动中自动完成：

1. 使用当前项目作为工作目录并寻找最新简历。
2. 从简历和已有岗位表推断届别、岗位方向、技术栈和实习需求。
3. 创建岗位 Excel 和薄弱点复习 Excel。
4. 立即执行一次岗位搜索、核实、匹配和去重。
5. 默认安排每天 8:00 更新岗位、9:00 开始面试。
6. 创建并置顶首个面试任务，立即提出第一道问题。
7. 默认每 7 天创建新面试任务，并继承未掌握的薄弱点。

重复发送`开始skill`不会清空记录或创建重复自动化，只会检查并补齐缺失部分。

如果项目中完全没有可读取的简历，也没有已有配置或岗位表，Skill 才会暂停并要求用户先提供简历。

### 通过 GitHub 安装

在 Codex 中发送：

```text
安装并使用这个 Skill：
https://github.com/junfengye02-spec/JobSearchTraining_skill
```

安装后，可以直接发送：

```text
开始skill
```

Skill 会优先从简历和已有文件推断设置，不重复询问能够自动确定的信息。用户仍然可以在消息中覆盖默认的每天 8:00 搜岗、9:00 面试和 7 天轮换设置。

### 开始一次岗位刷新

```text
使用 adaptive-interview-coach 刷新今天的目标岗位，并更新岗位 Excel。
```

### 开始一次面试

```text
使用 adaptive-interview-coach 根据我最新的简历和岗位职责开始面试。
```

### 查看复习情况

```text
使用 adaptive-interview-coach 查看当前薄弱点、到期复习项和岗位匹配情况。
```

## 运行时文件

Skill 不把用户数据提交到仓库。运行时会在用户选择的工作目录生成：

```text
岗位总表.xlsx
面试薄弱点复习表.xlsx
.adaptive-interview-coach/
├── config.json
├── state/jobs.json
├── state/discovery-runs.json
└── state/pending-weakness-updates.json
```

如果 Excel 正在被占用，Skill 不会创建副本，而是保留待写内容并在下一次运行时重试。

## 命令行脚本

Skill 内部提供四个脚本：

- `scripts/discovery.py`：生成四路搜索计划、校验来源覆盖并防止假空结果。
- `scripts/workspace.py`：初始化和查看工作区。
- `scripts/jobs.py`：岗位合并、去重、失效处理和 Excel 导出。
- `scripts/weaknesses.py`：薄弱点写入、复习记录、掌握度和到期复习。

脚本需要 Python 和 `openpyxl`。通常 Codex 会自动处理依赖；也可以手动安装：

```bash
python -m pip install openpyxl
```

## 隐私和数据边界

- Skill 本身不包含任何个人简历、联系方式、岗位历史、任务 ID 或本机绝对路径。
- 用户数据只写入自己的工作目录。
- 岗位信息必须来自可核实的公开来源。
- 网络错误、验证码或临时打不开页面不能直接判定岗位失效。
